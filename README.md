# Rangmanch — Where Talent Meets Opportunity

Rangmanch is an AI-assisted casting and talent discovery platform tailored for the Indian entertainment ecosystem (Bollywood, South Indian cinema, regional films, OTT web series, theatre, and commercial ads).

## Key Features
- **Cinematic Indian Design System**: Royal Crimson (`#990000`), Imperial Gold (`#D4AF37`), Deep Charcoal theme with Playfair Display & DM Sans typography.
- **AI Smart Compatibility Match**: Automatically calculates role-compatibility percentages based on spoken languages, dialects, age range, physical traits, and acting experience.
- **Multi-Role Experience**: Seamless switching between Actor/Talent, Casting Director, and Producer/Director views.
- **Audition Tape Management**: Digital headshots, comp cards, showreel links, and script sides for auditions.
- **Trust & Verification**: Verified production badges, anti-fraud safeguards, and zero-fee audition policies.

## Getting Started

First, run the development server:

```bash
npm run dev
```



## Tech Stack
- **Framework**: Next.js 16 (App Router) with React 19 & TypeScript.
- **Styling**: Tailored CSS design tokens & Lucide icons
- **State & UI**: Radix UI primitives, Zustand, Framer Motion.
